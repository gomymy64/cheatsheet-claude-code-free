Пошаговая инструкция

7 шагов от нуля до бесплатного Claude Code

ШАГ 01Открой конфигуратор моделей

Заходишь на наш сайт, выбираешь модель - и получаешь готовый промпт для настройки Claude Code.

Открой claude-code-models.vercel.app
Выбери вкладку "Set-up Code"
Выбери модель (например Gemini 3 Flash - 85% качества Claude за 10% цены)
ШАГ 02Получи API-ключ OpenRouter

Регистрируешься на OpenRouter и создаёшь ключ. Совет - положи $10 на баланс, это снимает рейт-лимиты даже для бесплатных моделей.

Зайди на openrouter.ai/keys
Нажми Create API Key
Дай имя ключу (например "free claude")
⚙️ Настройки: Credit limit → $15, Reset limit → Monthly, Expiration → оставь как есть
Положи $10 на баланс - даже для бесплатных моделей это убирает задержки и рейт-лимиты.
ШАГ 03Скопируй промпт и вставь в Antigravity

На конфигураторе уже готов промпт для выбранной модели. Копируешь и вставляешь в чат агента Antigravity - он сам настроит файл settings.json.

На конфигураторе нажми кнопку Copy
Открой Antigravity → окно агента (чат)
Вставь скопированный промпт в чат
Агент сам изменит ~/.claude/settings.json
ШАГ 04Проверь в терминале Antigravity

Настройки загружаются только при старте Claude Code. Открываешь терминал прямо в Antigravity и запускаешь claude.

В Antigravity: вверху нажми Terminal → New Terminal
Набери claude
В строке старта должна отобразиться выбранная модель
Если нет - закрой терминал полностью и открой новый
⌨️ КОМАНДА
claude
ШАГ 05Проверь что работает

Убедись что Claude Code подключился к нужной модели.

Спроси: "What model is this?" - модель назовёт себя
Попробуй создать что-нибудь (например попроси сгенерировать сайт)
Все скиллы Claude Code (команды через /) работают с любой моделью
ШАГ 06Как переключить модель

Хочешь попробовать другую модель? Не нужно заново всё настраивать.

На конфигураторе выбери вкладку "Change Code"
Выбери другую модель → нажми Copy
Вставь в Claude Code → перезапусти терминал
ШАГ 07Как вернуться на Claude

Наигрался с бесплатными моделями и хочешь обратно на Claude? Один клик.

На конфигураторе нажми на карточку "Claude"
Скопируй промпт отката (он удалит настройки OpenRouter)
Вставь в Claude Code → перезапусти терминал - снова Opus/Sonnet

Важно знать
